DevTinder App — Frontend

A fully responsive and modern dating application frontend built with React, Tailwind CSS, Redux Toolkit, Socket.IO Client, and Razorpay.

Users can create accounts, log in, update profiles, browse their feed, send interests, check received requests, manage connections, chat in real-time, and access premium features using Razorpay payments.

This repository contains only the UI + client-side logic.
